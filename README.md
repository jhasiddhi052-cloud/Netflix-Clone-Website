# 🎬 Netflix Clone Website

A responsive **Netflix Clone Website** built using **HTML and CSS**.
This project is created as a frontend development practice project to recreate the look and feel of the Netflix homepage with a clean and modern user interface.

## 📌 About The Project

This project is a frontend clone of the Netflix website. It focuses on creating a visually appealing streaming-platform interface using only **HTML and CSS**.

The main goal of this project was to practice:

* Structuring webpages using HTML
* Styling and designing layouts using CSS
* Creating responsive sections
* Working with images and backgrounds
* Using Flexbox for layout
* Creating a Netflix-inspired user interface

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## ✨ Features

* 🎬 Netflix-inspired homepage
* 🖼️ Movie and TV show sections
* 🎨 Modern dark-themed UI
* 📱 Responsive layout
* 🔥 Hero/banner section
* 🎞️ Movie thumbnails and cards
* 🧭 Navigation bar
* 📄 Clean and structured HTML
* 🎨 Custom CSS styling
